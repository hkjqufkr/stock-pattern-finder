# Stock Pattern Finder — 국내 주식 차트 유사도 검색

실제 국내 상장 종목의 일봉 데이터를 이용해 선택한 기준 패턴과 유사한 최근 차트 구간을 검색하는 Streamlit 웹앱입니다.

## 실행

Python 3.10 이상 권장:

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 표시되는 로컬 주소(보통 http://localhost:8501)를 엽니다. 인터넷 연결이 필요합니다.

## 사용법

1. 기준 종목명 또는 6자리 종목코드를 입력합니다(기본값 현대약품 004310).
2. 시작일·종료일을 지정하거나 기준 차트에서 드래그로 구간을 선택합니다. Plotly 차트 선택 기능은 Streamlit 버전에 따라 동작이 다를 수 있으므로 날짜 입력을 기본으로 제공합니다.
3. 코스피/코스닥 검색 범위, 종목 수, 검색 시점, 검색 기간 배율을 설정합니다.
4. 검색을 실행하고 상위 결과의 가격·거래량을 겹쳐 확인합니다.

## 데이터

- FinanceDataReader의 KRX 상장목록과 일봉을 우선 사용합니다.
- 일봉 요청 실패 시 pykrx를 대체 경로로 사용합니다.
- 제공처 정책 변경, 호출 제한, 휴장, 상장폐지, 종목코드 변경에 따라 일부 조회가 실패할 수 있습니다.
- KRX 전체 검색은 수천 종목의 데이터를 수집해야 하므로 첫 실행이 오래 걸릴 수 있습니다. Streamlit 캐시가 적용됩니다. 처음에는 50~100종목으로 테스트하세요.
- 종목 검색 목록은 현재 상장 목록 기준으로, 과거 상장폐지 종목은 포함되지 않습니다(생존 편향).

## 알고리즘

- 가격: 시작점 100으로 정규화한 로그가격 경로의 constrained DTW (70%)
- 거래량: log1p 거래량을 20일 이동 중앙값 대비 로그 비율로 변환한 constrained DTW (20%)
- 추세/변동성: 누적수익률·최대낙폭·일간 변동성·선형 추세의 정규화된 거리 (10%)
- 검색 대상 구간은 기준 구간 길이의 0.75~1.25배(설정 가능)로 샘플링하며 64개 점으로 리샘플링합니다.
- 유사도 점수는 0~100의 상대적인 거리 변환값으로, 통계적 확률이나 미래 수익률을 의미하지 않습니다.
- 거래량 지표는 기업 규모 차이 영향을 줄이기 위해 각 종목의 자체 기준으로 표준화합니다.

## 주의

차트 유사성은 매집, 시세조종, 향후 급등의 증거가 아닙니다. 실제 투자는 재무, 공시, 수급, 유동성 등을 별도로 확인해야 합니다.
